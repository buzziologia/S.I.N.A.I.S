S.I.N.A.I.S - Onde estão os checkpoints da rede neural
=======================================================

Pasta:  models/saved_weights/

Cada treino gera um PAR de arquivos com o mesmo prefixo (timestamp do treino):

  {id}_modelo.pth     -> os pesos da rede (state_dict do PyTorch, salvo na
                         melhor época de validação pelo scripts/train.py)
  {id}_classes.json   -> o mapeamento índice -> palavra daquele treino
                         (os scripts localizam automaticamente pelo prefixo)

Arquivos {id}_ood_*.npz na mesma pasta NÃO são checkpoints: são o cache do
banco de detecção fora-do-vocabulário (OOD) usado pelo testar_camera.py,
gerado a partir do modelo na primeira execução.

Como usar um checkpoint
-----------------------

    # webcam
    python scripts/testar_camera.py --pesos models/saved_weights/{id}_modelo.pth

    # avaliação no hold-out
    python scripts/avaliar_holdout.py --pesos models/saved_weights/{id}_modelo.pth

    # em código Python:
    #   modelo = LIBRASClassifier(input_dim=126, num_classes=N)
    #   modelo.load_state_dict(torch.load('models/saved_weights/{id}_modelo.pth'))
    #   (N = len(classes) do {id}_classes.json)

Sem --pesos, os scripts carregam o *_modelo.pth mais recente da pasta.

Todos os checkpoints acima estão versionados no git (acompanham o clone).
Um novo treino (scripts/train.py) cria um novo par {timestamp}_* na mesma
pasta, sem sobrescrever os anteriores.
